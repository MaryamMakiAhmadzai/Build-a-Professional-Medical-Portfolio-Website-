# Dr. Khalid Khan Zadran — React Portfolio

Professional responsive React website built with Vite, React Router DOM, Tailwind CSS v4, Motion, and Lucide React.

## Run locally
1. Install Node.js LTS if it is not already installed.
2. Open this folder in VS Code.
3. Open Terminal inside this folder.
4. Run:
   ```bash
   npm install
   npm run dev
   ```
5. Open the local URL shown by Vite (usually http://localhost:5173).

## Production build
```bash
npm run build
npm run preview
```

## Pages
- `/` Home
- `/about` About
- `/qualifications` Qualifications and memberships
- `/specializations` Clinical focus areas
- `/contact` Clinic details and consultation enquiry form
- Any unknown route shows a 404 page

## Notes before publishing
- The doctor/clinic details are based on information supplied for the assignment. Confirm phone, credentials, memberships, and clinic details with the doctor before publishing.
- Images are representative stock images, not verified photos of Dr. Khalid Khan Zadran.
- The consultation form opens the visitor's email app; it does not store submissions or send them to a server. A real booking workflow needs a verified email/backend.
- Clinic hours and an exact map address were not supplied, so neither is invented.
